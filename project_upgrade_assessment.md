# Оценка обновления проекта RxMarbles

## Общий обзор проекта

**RxMarbles** - это iOS приложение для изучения RxSwift операторов с интерактивными диаграммами. Проект использует устаревшие версии технологий, но благодаря автоматическим инструментам миграции Xcode обновление будет значительно проще.

### Текущее состояние

**Версии технологий:**
- Swift: 4.0/5.0 (устарело)
- RxSwift: 4.4.1 (устарело)
- RxCocoa: 4.4.1 (устарело)
- iOS Deployment Target: 11.0 (устарело)
- Xcode: совместимость до 12.5 (устарело)

**Зависимости:**
- Device: 3.1.2
- Fabric/Crashlytics: 3.12.0/1.9.0 (устарело)
- RazzleDazzle: 0.2.0

## 2. Обновление RxSwift

### Автоматическое обновление зависимостей

**Podfile обновление:**
```ruby
# Обновленный Podfile
use_frameworks!

target 'RxMarbles' do
  pod 'RxSwift', '~> 6.9'
  pod 'RxCocoa', '~> 6.9'
  pod 'Device', '~> 3.4'
  # Заменяем Fabric на Firebase
  pod 'FirebaseCrashlytics'
  pod 'RazzleDazzle', :git => 'https://github.com/carlosypunto/RazzleDazzle.git', :tag => '0.2.0'
end

post_install do |installer|
  installer.pods_project.targets.each do |target|
    target.build_configurations.each do |configuration|
      configuration.build_settings['SWIFT_VERSION'] = "6.0"
    end
  end
end
```

### RxSwift Migration Tool

**✅ Xcode + RxSwift предоставляют:**
- Автоматическое переименование операторов
- Fix-it suggestions для deprecated API
- Automatic refactoring для большинства изменений

**Основные автоматические замены:**
- `catchError(_:)` → `catch(_:)` ✅ Автоматически
- `catchErrorJustReturn(_:)` → `catchAndReturn(_:)` ✅ Автоматически
- `elementAt(_:)` → `element(at:)` ✅ Автоматически
- `observeOn`/`subscribeOn` → `observe(on:)`/`subscribe(on:)` ✅ Автоматически

**Ручная проверка потребуется только для:**
- Custom операторов (если есть)
- Сложных closure chains
- Error handling логики

**Оценка сложности: НИЗКАЯ** (автоматическая миграция)
**Время: 3-4 часа** (вместо 12-15)
